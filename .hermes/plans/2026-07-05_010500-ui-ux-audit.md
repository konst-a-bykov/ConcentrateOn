# ConcentrateOn Web — UI/UX Audit & Improvement Plan

## Summary

A professional UI/UX audit of the ConcentrateOn web app, covering the Home page (timer + animation), Settings, Statistics, About, navigation, and responsive design. Prioritized by impact.

---

## Critical Issues (High Impact)

### 1. Timer Controls at Top — Wrong Ergonomics

**Problem:** Controls sit at the top of the screen. On mobile (the primary use case for a timer), users hold phones at the bottom. The Start/Pause/Stop buttons require reaching to the top, which is uncomfortable and non-standard.

**Evidence:** Every major timer app (iOS Clock, Forest, Focus Keeper, Pomofree) places controls at the bottom.

**Fix:** Move the timer card to the bottom-center of the viewport. Menu button stays top-left.

**Files:** `src/pages/Home.tsx`

---

### 2. No Progress Visualization

**Problem:** The timer shows numbers counting down (`24:37`) but there's no visual progress indicator. Users can't glance and instantly see "I'm 60% done." The animation changes between work/rest states but doesn't reflect progress within a period.

**Fix:** Add a circular progress ring around the timer or a thin progress bar at the bottom of the timer card. The ring could use the same error/success color coding (red for work, green for rest).

**Files:** New component `src/components/ProgressRing.tsx`, update `TimerDisplay.tsx`

---

### 3. Timer Card Looks Floating/Disconnected

**Problem:** The timer card uses a semi-transparent `rgba(255,255,255,0.2)` background with backdrop blur. It looks like a temporary overlay, not part of the design. On dark backgrounds it can be hard to read.

**Fix:** Give the timer card a more intentional design — either a proper glass-morphism style with stronger border, or a solid card that matches the animation's visual language. Consider a thin border (`border border-white/20`) for better definition.

**Files:** `src/pages/Home.tsx`

---

## Significant Issues (Medium Impact)

### 4. Menu Button is Too Subtle

**Problem:** The hamburger menu button is `btn-sm` (32px) in the corner. On a full-screen animation, it's easy to miss. Users might not know how to access Settings.

**Fix:** Either:
- Make the button slightly larger (`btn-md`)
- Add a subtle tooltip on first visit ("Tap here for settings")
- Or show a brief onboarding overlay on first load

**Files:** `src/pages/Home.tsx`

---

### 5. Settings Page — Input Fields are Too Narrow

**Problem:** All number inputs are `w-32` (128px). On wider screens this looks cramped. The labels are on the left, inputs on the right — on mobile this can wrap awkwardly.

**Fix:** Use a stacked layout (label above input) on mobile, side-by-side on desktop. Widen inputs to `w-full max-w-[200px]` for better touch targets.

**Files:** `src/pages/Settings.tsx`

---

### 6. Settings Page — No Visual Feedback on Save

**Problem:** Settings save instantly (Zustand), but there's no visual feedback. Users don't know if their change was applied.

**Fix:** Add a subtle toast notification ("Settings saved") or a brief highlight animation on the changed value.

**Files:** `src/pages/Settings.tsx`, new `src/components/Toast.tsx` or use DaisyUI toast

---

### 7. Volume Control is a Dropdown — Should Be a Slider

**Problem:** Volume is a dropdown with 5 options (0/25/50/75/100%). A slider would be more intuitive and allow finer control.

**Fix:** Replace the dropdown with an `<input type="range">` styled with DaisyUI/Tailwind, showing the current value.

**Files:** `src/pages/Settings.tsx`

---

### 8. Statistics Page — Empty State is Weak

**Problem:** The empty state just says "No activity logged yet." This is a wasted opportunity to guide the user.

**Fix:** Add an illustration or icon, a brief explanation of what will appear here, and a "Start a timer" CTA button that navigates to Home.

**Files:** `src/pages/Statistics.tsx`

---

### 9. Statistics Page — No Date Grouping

**Problem:** Entries are listed as a flat table. For a user with many sessions, this becomes a wall of text.

**Fix:** Group entries by date (Today, Yesterday, This Week, Older). Add relative timestamps ("2 hours ago") alongside absolute dates.

**Files:** `src/pages/Statistics.tsx`

---

### 10. Inconsistent Page Transitions

**Problem:** Home is full-viewport with a video. Other pages have a navbar + scrollable content. The transition between them is jarring — the animation disappears, a navbar appears, the layout completely changes.

**Fix:** Consider keeping a subtle animation or colored background on other pages, or add a page transition animation (fade/slide) using CSS or a library like `framer-motion`.

**Files:** `src/components/Layout.tsx`, `src/App.tsx`

---

## Polish Issues (Lower Impact)

### 11. About Page is Text-Heavy

**Problem:** The About page has 3 text-heavy cards. Most users won't read walls of text.

**Fix:** Add icons to each card, use shorter paragraphs, add a visual timeline for the Pomodoro technique steps.

**Files:** `src/pages/About.tsx`

---

### 12. No Keyboard Shortcuts

**Problem:** Power users can't control the timer with keyboard. Space for start/pause, Escape for stop would be natural.

**Fix:** Add `useEffect` with `keydown` listener on Home page.

**Files:** `src/pages/Home.tsx`

---

### 13. Dark Mode — Animation Background

**Problem:** In dark mode, the `bg-base-200` on the AnimationPlayer container creates a visible frame around the video that clashes with the dark theme.

**Fix:** Use `bg-base-300` or a custom dark color that blends with the video's letterboxing.

**Files:** `src/engine/AnimationPlayer.tsx`

---

### 14. Missing Page Titles / Meta Tags

**Problem:** All pages share the same `<title>ConcentrateOn</title>`. No per-page meta descriptions for SEO or social sharing.

**Fix:** Use `react-helmet-async` or a simple `useEffect` to set `document.title` per page.

**Files:** New `src/hooks/usePageTitle.ts`, update each page
