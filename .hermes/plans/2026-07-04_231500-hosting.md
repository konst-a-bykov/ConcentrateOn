# ConcentrateOn Web — Hosting Plan

## Context

The web app is a **pure static SPA** — no backend, no server-side code. The build output is:
- `dist/` folder: ~300KB (JS + CSS + HTML + PWA service worker)
- `public/animations/ancient-man/`: ~2.7MB (WebM videos + PNGs + MP3s)
- **Total deploy size: ~3MB**

No database, no API, no Node.js runtime needed. Just serve static files over HTTPS.

## Hosting Options

| Option | Cost | Pros | Cons |
|--------|------|------|------|
| **Contabo VPS** (already have) | $5/mo (shared) | Full control, can host other projects | Overkill for static files, manual setup (nginx/caddy), no CDN, no auto-SSL, maintenance burden |
| **GitHub Pages** | Free | Auto-deploy on push, HTTPS, zero maintenance, custom domain support | No server-side logic (not needed here), 100GB bandwidth limit |
| **Vercel** | Free | Auto-deploy, global CDN, instant rollbacks, preview deploys, HTTPS | Free tier has limits (but way above this project's needs) |
| **Cloudflare Pages** | Free | Global CDN (fastest), auto-deploy, unlimited bandwidth, free SSL | Slightly more complex setup than Vercel |
| **Netlify** | Free | Auto-deploy, CDN, HTTPS, form handling | Free tier 100GB bandwidth |

## Recommendation

**Use GitHub Pages or Vercel.** Both are free, require zero maintenance, and auto-deploy on `git push`. Since the project is already in a git repo, the deploy flow is:

```
git push → GitHub Actions → build → deploy
```

There's no reason to pay $5/month for a VPS to serve 3MB of static files. Save the Contabo server for projects that actually need a backend.

### If you prefer one over the other:

- **GitHub Pages** — simplest, already on GitHub, zero config. Just enable it in repo settings + add a deploy workflow.
- **Vercel** — better DX, faster global CDN, preview deploys for PRs, auto-detects Vite.

## Step-by-Step: GitHub Pages

1. Add `vite.config.ts` base path (if not deploying to root domain):
   ```ts
   base: '/concentrateon-web/',
   ```

2. Add `.github/workflows/deploy.yml`:
   - Trigger on push to `main`
   - Node 20, `npm ci && npm run build`
   - Upload `dist/` to GitHub Pages

3. Enable GitHub Pages in repo settings → Source: GitHub Actions

4. Done. Site at `https://<username>.github.io/concentrateon-web/`

## Step-by-Step: Vercel

1. `npm i -g vercel`
2. `vercel` in project root → follow prompts
3. Connect GitHub repo → auto-deploys on every push
4. Custom domain via Vercel dashboard (optional)

## Files Changed

- `concentrateon-web/vite.config.ts` — add `base` path (GitHub Pages only)
- `concentrateon-web/.github/workflows/deploy.yml` — CI/CD workflow (GitHub Pages only)
- Or: `concentrateon-web/vercel.json` — Vercel config (if choosing Vercel)
